## 🚀 Featured Projects

### 🤖 [Prompt Form AI](https://github.com/akshay-appala/prompt-form-ai)

An AI-powered form builder that transforms natural-language prompts into structured, customizable forms using the **Google Gemini API**.

- 🧠 Generates forms from natural-language prompts while following a predefined schema
- 🗄️ Stores generated forms and responses using **MongoDB & Mongoose**
- 🔐 Includes **JWT-based authentication** and protected REST APIs
- ⚙️ Built with the **MERN stack** and integrated with Gemini
- 🎯 Designed to maintain consistency between AI-generated form structures and the application's database schema

**Tech:** React · Node.js · Express.js · MongoDB · Mongoose · Gemini API · JWT

### 🧩 [Essence AI](https://github.com/akshay-appala/essence-ai)

An AI-powered **Chrome Extension** that summarizes web content using **Google Gemini** through a Node.js & Express.js backend.

- 🌐 Built as a **Chrome Extension using Manifest V3**

- 🧠 Supports **Brief, Bullet Point, and Detailed** summarization modes
- 🔧 Integrates Chrome Extension APIs with LLM-powered backend services

**Tech:** JavaScript · Chrome Extension APIs · Node.js · Express.js · Gemini API
